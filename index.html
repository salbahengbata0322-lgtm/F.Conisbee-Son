Turkey Allocation Planning

Buckets every Whole Turkey and Crown/Misc order line by weight band, so you know how many birds of each size to source. "Allocated" means a Turkey Number has been filled in on that order line (Order Entry's Turkey detail fields) — i.e. a real bird has been matched to it. "In Stock" comes from the Turkey Stock page. "Spare / Short" is stock minus ordered: red means short, amber means within 10% of running out, green means enough. Cancelled orders are left out.

Backup

Supabase's free tier doesn't include automated backups. Click one of the buttons below every so often (once a week is a reasonable habit) and save the downloaded file somewhere safe — a cloud drive folder, or emailed to yourself. Either one is a complete snapshot of every customer, order, payment, sale, and product.

Excel — for actually looking at the data (opens straight into a normal spreadsheet, one tab per table). JSON — the more exact, restore-from-scratch version, meant to be re-imported rather than read directly.

Season

At the start of a new Christmas, take a backup first, then start the new season. Last season's orders stay on record and can still be viewed with the Season box at the top. New orders go into the new season.

Security — Two-Factor Authentication

This protects your own login only — each staff member sets this up for themselves while logged in. If you lose access to your authenticator app, someone with access to the Supabase dashboard will need to manually remove your 2FA to let you back in — there's no automatic "forgot my code" recovery.

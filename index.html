Backup

Supabase's free tier doesn't include automated backups. Click one of the buttons below every so often (once a week is a reasonable habit) and save the downloaded file somewhere safe — a cloud drive folder, or emailed to yourself. Either one is a complete snapshot of every customer, order, payment, sale, and product.

Excel — for actually looking at the data (opens straight into a normal spreadsheet, one tab per table). JSON — the more exact, restore-from-scratch version, meant to be re-imported rather than read directly.

Security — Two-Factor Authentication
